# PandorasBox

│   └── first_trial.json
├── dialogues/

│   ├── awakening_complete.json
│   ├── first_trial_complete.json
│   ├── death_comment_1.json
│   ├── death_comment_2.json
│   ├── death_comment_3.json

│   └── response_curious.json

│   └── response_skeptical.json
└── events/
    └── player_actions.json
